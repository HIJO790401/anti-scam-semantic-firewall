## 純邏輯系統進度文檔（可雲端保存 / 跨視窗對齊）

## 1) 系統現況快照（v3.1）

目前系統由一個主頁 `index.html` 搭配 5 個邏輯模組 + 3 份資料檔組成：

- 核心風險引擎：`js/scbkr-engine.js`
- 範例載入：`js/examples-loader.js`
- 語音朗讀：`js/voice.js`
- 報告匯出：`js/report-export.js`
- 多語系：`js/i18n.js`
- 詐騙範例資料：`data/examples.json`
- 多語文字資源：`i18n/zh.json`, `i18n/en.json`

核心原則：
1. 不連外部 AI API。
2. 不把輸入訊息送出到外部服務。
3. 三模式（標準 / 專業 / 長輩）皆保留。
4. 分析規則由本地關鍵詞與責任鏈規則決定。

## 2) SCBKR 核心判斷邏輯（純規則）

### 2.1 特徵偵測（Pattern Detection）
引擎先把文字轉小寫後，檢測以下模式：

- `hasUrgent`：急迫語氣（立即、限時、asap、10分鐘等）
- `hasMoney`：金流相關（轉帳、匯款、帳戶、投資、驗證碼等）
- `hasApp`：要求安裝/下載 app 或遠端協助
- `hasLink`：網址/連結相關
- `hasOfficial`：是否提及官方機構詞（銀行、客服等）
- `asksSecret`：是否索取密碼/驗證碼/卡片資訊
- `hasThreat`：威脅詞（凍結、停權、罰款等）

並推導：
- `hasAnyScamPattern = hasMoney || hasApp || hasLink || asksSecret || hasThreat`

### 2.2 SCBKR 五軸布林值
- `S`（Subject）：`hasOfficial`
- `C`（Cause）：是否有「因為/由於/通知/告知/提醒」
- `B`（Boundary）：是否有「請在/請點選/請輸入/請提供...」
- `K`（Cost）：是否提到損失/風險/金額/款項或威脅
- `R`（Responsibility）：是否有客服/專線/疑問聯繫說明

### 2.3 風險分級規則
1. **FATAL**：
   - `(hasMoney || asksSecret) && (hasLink || hasApp) && hasUrgent`
2. **NON-CLOSABLE**：
   - `hasAnyScamPattern && (SCBKR true 軸數 <= 2)`
3. **RISK**：
   - `hasAnyScamPattern`
4. **SAFE**：
   - 以上皆否

> 這套順序是硬規則，先判 FATAL，再判 NON-CLOSABLE，再判 RISK，最後 SAFE。

## 3) 分析輸出資料結構（對齊討論用）

`analyzeMessage(text)` 會輸出：

- `risk`: `SAFE | RISK | FATAL | NON-CLOSABLE`
- `scbkr`: `{ S, C, B, K, R }`（布林）
- `reasons`: 觸發的可疑語意說明陣列
- `debug`: pattern 命中細節
- `riskDisplay`: 畫面展示文字（標籤 / 主說明 / 次說明 / badge class）

建議跨視窗討論時固定用這 5 個欄位，不容易失焦。

## 4) UI 三模式行為規格

### 4.1 標準版（standard）
- 一般使用者預設模式。
- 提供輸入、分析、清除。

### 4.2 專業版（pro）
- 顯示 debug 區塊（規則命中資訊）。
- 額外顯示「匯出報告」按鈕。

### 4.3 長輩版（senior）
- 大字體與簡化閱讀導向。
- 額外顯示「朗讀風險結果 / 停止朗讀」。

## 5) 新增模組責任邊界（誰負責什麼）

### `js/scbkr-engine.js`
- 只做語意規則分析與風險分級。
- 不碰 DOM。

### `js/examples-loader.js`
- 載入 `data/examples.json`。
- 產生範例下拉。
- 選擇後「只填入」輸入框，不自動分析。

### `js/voice.js`
- 封裝 `speechSynthesis`。
- `speakRiskResult(resultObj, lang)` / `stopSpeaking()`。

### `js/report-export.js`
- 根據結果物件產生簡化報告頁。
- 呼叫 `print()` 供使用者另存 PDF。

### `js/i18n.js`
- 動態載入語言資源。
- 提供 `t(key)`。
- 切換語言後即時刷新帶 `data-i18n` 的節點。
